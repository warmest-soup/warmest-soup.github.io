Stickers:
Gadgets are tools embedded into one's message that provide helpful functions to chat users. They are used appending a "!" to the begining of their name.

Scheduler: A GMT to Local time converter. LOCAL time is relative to the person viewing it, and is automatically adjusted for each chat member. The Scheduler's input is in d/m/y and 24-hour format.
Pressing the "Copy" button, will copy the GMT equivalent of the entered time, preformatted with the t| markdown. this can be pasted into a message to coordinate events.

Markdown is performed by enclosing text in "bars"
like this: ib|This text will be bold AND italicized|
The following markdown options are available;

B Bold: b|This text will be bold|

I Italic: i|This text will be italicized|

- Strikethrough: -|This text will be crossed out|

_ Underline: _|This text will be underlined|



C. Color: Color must be the final tag used, for example bc.red|text| will result in bold red text, while c.redb|Text| will result in failure.
C. takes any valid CSS color, including named colors, hexcodes, transparency, and rgb() & hsl() formats.
c.cyan|This text will be colored|

F() Animated: f() requires a named CSS animation to play, a list of available animations is provided below. Animation names are case-sensitive but all animations intended for markDown will be named in all lowercase letters. To layer multiple animations seperate animation names with periods. example f(spin.grow.fade)
f(Glow)|This text will be animated|

T Local Time adjust: This markdown will convert GMT dates and times to the Local Timezones of those who view the message. It's possible for it to read many date formats, but the surest way to get the correct time & date is to copy a preformatted t| from the !Scheduler gadget.
t|Sat, 21 sep 1978 21:13 LOCAL|

a. Link: Formatted, clickable links that display clean text.
a.www.yourUrl.com|This text will become a clickable link|

vV Vertical orientation: the V tag has two functions, one for the lowercase "v" and one for the uppercase "V". The lowercase value will keep character orientation inline with the not vertical line orientation, while the uppercase variant will allow for the use of vertical fonts, such as 日本語. The v tag supports new lines, and only one set of bars is necessary for multiple lines of text.
v|This text will be vertical| whereas V|This text
will be
vertical|

D Downward text: The d tag actively rotates the given text around an anchor point set at the left hand side. this transformation disregards standard document flow, and can be used to strange effects.
d|This text will be rotated downward.|




As shown here, the rotated text
covers text below it.





XY Horizontal and Vertical mirroring: The x tag will flip it's contents horizontally, while the y tag will flip it's content vertically, by putting "xy" both axises may be mirrored at once.
x|This text will be backwards|

CW() Clockwise rotation: This tag will rotate it's context clockwise a number of degrees equal to the number within it's parentheses. For counter-clockwise rotation, a negative number can be used.


cw(-45)|Rotated text.|

HR() Hue rotation: This tag will shift the color a number of degrees around the color wheel.


hr(180)||
